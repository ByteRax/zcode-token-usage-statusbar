## 小红书正文

```
⚡最近在用 ZCode 写代码，发现一个巨实用的插件——

Token 速度状态栏，装上之后输入框下面会多一条小状态条，
模型快不快、token 花了多少、上下文还剩多少，一眼就看明白了。

真的解决了我几个痛点：

1️⃣ 模型快不快不用猜了
生成速度直接显示 token/s，颜色还会变：绿色快、黄色一般、
红色慢，今天这个模型给不给力一眼就知道。

2️⃣ 用了多少心里有数
本轮 / 这次会话 / 今天一共，分开显示，不用跑去设置页翻半天。

3️⃣ 上下文要满了会提醒
进度条 + 百分比，快到上限了变色警告，不会写到一半突然报错断片。

还有个加分项：后台子代理的消耗单独统计，点一下还能看明细，
派了多少任务、花了多少 token 清清楚楚。

完全免费开源，用量数据只读本地、不上传，放心装。

安装也简单，三步：
① ZCode 设置 → 插件 → 添加插件市场，填
   github.com/ByteRax/zcode-token-usage-statusbar#plugin-releases
② 任意对话框输入 /install-overlay
③ 重启 ZCode，状态条就出现了

#AI编程 #ZCode #效率工具 #程序员日常 #编程工具推荐
```

## 备注

- 市场地址已统一改为正式渠道 `#plugin-releases`（2026-10-21 定）：装的是经过校验的正式 Release 包，更新也跟随正式版。推广口径与仓库 README 一致。
- 装好后新建或恢复会话，插件自动安装状态条（始终开启）；没装上再在对话框输入 `/install-overlay` 兜底，成功后完全退出并重开 ZCode 才会显示。
