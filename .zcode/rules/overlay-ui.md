# 桌面浮层与展示口径规则

适用路径：`overlay.js`（及 `plugins/zcode-token-usage-statusbar/overlay.js` 副本）、`turn-stats.js`、`inject-main.cjs` 中与浮层交互的推送/热重载/Git 状态段、`tests/overlay-*.test.cjs`。Web 浮层 `web/overlay.js` 是独立实现，见 [web.md](web.md)。

改动浮层、tooltip、⚙ 面板、原生按钮增强、统计行或任何用户可见数字/文案前先读本文件；全局约定见根 [AGENTS.md](../../AGENTS.md) §4、§5。

## 1. 文件与版本契约

- `overlay.js` 顶部 `VERSION` 随**提交**递增，未提交的中间迭代不涨号；并行会话/工作树叠加时撞号须按合入顺序顺延改号并合并注释后再提交。版本注释是代际变更的唯一就地记录。
- 顶层常量（如 `SRC_FIELD_LABELS`、进度阶段表、签名缓存）必须在 `buildPanel` 等消费函数定义**之前**赋值，`var` 提升不会提升初始值，曾因时序在面板打开时崩溃。
- 浮层是注入宿主渲染进程的脚本：保留代际守卫（`__zusageDispose` 移除旧条再重注入）、幂等内容更新、tooltip 解绑与扫描清理；`rAF` 自调度必须在异常后继续下一帧；诊断对象原地更新，不替换闭包共享引用。
- 热重载：主桥每 2s stat 运行目录 `overlay.js`/`turn-stats.js` mtime（`config.hot_reload !== false`），变化即 cleanup + 重注入，`turn-stats.js` 先于 `overlay.js`。主进程新增推送字段时渲染端必须判空不渲染或整块隐藏——热文件可能先于冷文件部署，字段缺失是常态不是错误。
- 新增定时器、DOM/IPC 监听器要有明确归属，并验证热更新、导航、窗口关闭后停用；不能声称已有完整全局 dispose。

## 2. 挂载与几何

- 默认状态条优先挂输入卡片工具行之后，找不到工具行时才回退到 body 级 `position: fixed`；样式挂条内 `<style>`。药丸样式固定在所属输入卡片下方、按内容定宽并居中。几何避开输入框中心点命中检测，避免自遮挡闪烁；面板和 tooltip 挂 body。
- 默认样式卡内随卡片拉伸，悬浮回退锁定卡片实测宽；超宽时先隐藏「本轮」「会话累计」「项目累计」的缓存命中率（tooltip 仍可见），再以右缘渐隐兜底。药丸样式以输入卡及视口宽度约束，窄时条面横向滚动，聚焦条目应滚入可视区域；条面不换行。Web 宽度策略独立。**默认样式水平对齐（v226）**：`zusage3.barJust` 取 `between|start|end`（缺省/非法回退 between=基线 space-between 不挂类），仅默认档在条上挂 `zu-just-start`/`zu-just-end`（applyBarTheme 内 toggle，切档即摘）。**居右不用字面 `justify-content:flex-end`**——LTR 下 start 侧溢出不可滚动也不计入 scrollWidth，收缩检测失效、左格无声硬裁、`.zu-clip` 渐隐错边；改用 `.zu-just-end .zu-main > :first-child{margin-left:auto}`：自由空间被 auto margin 吸收等效右聚拢，溢出时 auto 归零、溢出方向与收缩/渐隐兜底不变（居左/居右/均分在溢出态视觉等价属预期）。⚙ 设置块 `.zu-just-block` 仅默认档可见，applyBarTheme 随档显隐（面板高度契约只收紧不放大，块重现时设置体滚动区变长）。
- **宿主标题栏拖拽区穿透（v254）**：Electron 桌面宿主多视图顶部有 48px `[app-region:drag]` 标题栏拖拽条，拖拽区按几何命中、穿透上层未显式标注 `no-drag` 的覆盖层（宿主自家每个浮层都标 no-drag、并用全屏 `no-drag` 屏障）——挂 body 的浮层根（`.zusage-panel`/`.tip`/`.zu-mp-ov`/`.zu-compact-dlg`/`.zusage-exc`）必须显式 `-webkit-app-region:no-drag` 把自身矩形从拖拽区减掉，否则与条带重叠的头部（如设置面板 top:8px 的 ✕、极矮视口下 top clamp 8px 的超限气泡）真实点击被窗口拖拽吞掉。**新增 body 级浮层根必须挂进该规则**（`tests/overlay-settings.test.cjs` 有规则串与类名挂载点双断言）；Web 端无此机制，不适用。
- ⚙ 通用的「状态条样式」持久化为 `zusage3.theme`（`default` / `pill` / `compact`，缺省与非法值回退 `default`），主题切换只写该键，同窗实例同步。**v226 自动精简例外**：六个格开关（turn/win/proj/tools/today/sub，`SHOW_CELLS` 在 setBarTheme 旁）全部关闭的**边缘触发**自动切 compact（default 与 pill 来源都触发；git/subRate 不在条面不参与），`zusage3.autoCompact` 记录来源主题，重开任一格恢复并清标记；面板手动改档即清标记解除自动（无标记不写，边缘触发保证手动改回默认不立即翻回；残留标记在重开格子时防御清理）。手动选精简不带标记，不自动切回。药丸表面跟随所属输入卡的圆角、边框、背景以及 Highspeed/焦点状态；不改变数字单位、额度口径或工具栏 chip。
- **更新日志卡片（v202）**：⚙ 插件更新分区第二张卡（同款 `.zu-settings-card`）。默认日志按可靠状态选择：待重启=marker 版本（退 pendingRelease 目标、再退 updated latestVersion；身份无法确定明示不冒充）；安装中=安装目标；error+lastFailure=失败目标并标「未安装成功」；available/updated/current 各对应该版本。正文是转义优先的受限 Markdown（禁任意 HTML 与图片，链接仅 https 且点击走 openExternal，URL 带 600 上限）；「升级注意」类标题节（升级/注意/兼容/Breaking/Upgrade/Attention/Important/⚠）折叠时无论位置均完整可见并高亮（追加在预览之后，不重排原文顺序），其余内容折叠时只隐藏不丢弃并提示「还有更多」。用户选择历史版本后粘性不随轮询切回（「返回默认版本」入口在选择≠默认时显示；被默认追上即自然失效并显示真实状态）；正文按签名幂等重建（保滚动/焦点）；拉取失败只降级卡片，不拖垮面板（`__zusageDiag.notesErr`），也不影响检查更新/立即更新/重启按钮。渠道策略（2026-11-01 用户拍板「拿同号 Release 展示，忽略渠道」）：Release 渠道取本渠道 Release（verified）；market 源码渠道取注册仓库的**同号 Release 参考正文**（`verified:false`，meta 追加「参考：同号 Release，未核实与本渠道一致」、链接用参考措辞）；本地目录无仓库身份仍离线空状态。未检查（channel 未知）时当前已装版本即默认目标，直接拉取由主进程门控裁决。
- **精简模式（compact，v146；v226 起另有六格全关自动进入路径，见上条自动精简例外）**：条永久 `display:none` 但**保留 DOM**——chip 样式 `<style>` 与 ariaLive 都挂条内（`<style>` 隐藏仍全局生效），`heavy()` 每拍保条回 body 对抗 React 清子树（条丢=chip 样式全灭），`render()` 跳过条面重建但数据解析与 enhance 照跑；`track()` 早退只留诊断（`FATAL.mount.mode="compact"`）。速率 chip `.zu-tsb` 挂工具行前导区、git chip 左侧（git 在时插其前、不在时占其锚位=cua-entry 后方；两侧兜回收敛为 [锚][速率][git]，git 兜回容忍速率占相邻位防拉锯；判位用 nextElementSibling——nextSibling 会被文本节点打乱成每拍重插；前导区发现失败回落尾随区重置卡/额度组左侧），内容与条面速度 chip 同源，**无有效样本不渲染（用户拍板）**——代价是新会话首次请求前无设置入口；隐藏格数据收进速率 chip tooltip 的「状态条摘要」行（逐格开关 `state.show.*` 继续生效、子代理行点击开明细）+「打开设置」按钮（镜像齿轮开启分支）。已知限制：条隐藏后 ariaLive 不播报（`display:none` 后代），chip 仍有 aria-label。面板/子面板在精简下几何改锚输入卡/chip（条 rect 为 0）。
- 字体一律引用宿主令牌：字号 `calc(var(--ui-font-size, 14px) ± Npx)`，字族 `var(--font-mono, <旧硬编码栈>)`，用 font longhand 不用简写；`--ui-font-size` 由宿主设置页运行时写在 `html` 内联样式。配色走宿主 `--color-*` 变量自动适配亮暗，引用前确认令牌存在。**例外（2026-10-28 用户规格定稿）**：额度 chip `.zu-quota` 与上下文百分比 `.zu-ctxpct` 两处**显式同字体**：`calc(var(--text-ui-base,var(--ui-font-size,14px)) - 1px)` + 加粗 + `var(--font-mono,…)` + tabular-nums（宿主默认基准 14px 时为 13px）——不靠继承（工具栏容器字号偏小、与带 `text-ui-base` 的按钮不等值，实测两段字号不一致），`.pct` 半加粗废止。其余条目（git chip、⚙ 面板等）仍走宿主令牌。
- 幽灵判定 `inGhostSubtree` 只管聊天壳：宿主用 `opacity-0 + inert` 保持聊天视图挂载，`opacity < 0.1` 的祖先会被判死不挂条，布景/演示页不能用 opacity 隐藏挂靠卡片。
- **辅助对话独立状态条（v174/v175）**：划词 side chat 复用主会话 SessionPane（无外层 `data-pane-id`），协调器按宿主 tabId 识别；主分栏和当前可见辅助对话的实例配额相互独立。辅助实例仅在本地身份经桥 scope 验证时读取会话数据和绑定 store，身份未知或远端不得借本地数据；确定性统计行按会话根归属；回答末尾富文本与主分栏同规则——显式本地 scope + `isCurrentTurn` 活跃轮限定 + `--current` 的 promptTs 守卫（辅助会话 prompt hook 以 child sid 记录提问时刻）。已知宿主限制：投影 `modelDurationMs` 只累计高速供应商（`isHighspeedProviderId` 门控），普通模型轮次 tracker 无速率、占位行显示「生成时长缺失」直至富文本到达。
- ⚙ 设置面板结构（用户拍板）：ZCode 设置侧栏同款——左栏三组分区导航 + 右侧单分区显隐，激活项 `aria-current="page"`，选择持久化 `zusage3.sec`，面板窄于 620px 时导航收成 icon rail；高度在打开瞬间按内容自然高锁定，此后只收紧不放大（切分区不抖动，留白是预期）。配色全走宿主 `--color-*` 语义变量。

## 3. React 对抗与宿主 DOM 挂靠

- 三板斧：① 宿主元素上用 `data-zusage-*` 属性驱动 CSS（React 不清理非 props 属性；改 class 会被 className 整串重写抹掉）；② 静态几何用 CSS 覆盖 SVG presentation attribute；③ 动态 dasharray/pathLength 由 JS 写入并在 render 与 heavy（600ms）两处 reapply 兜住 React 重写。
- 要继承宿主 hover-card/原生交互的手动节点必须挂进 React trigger 元素**内部**末尾（宿主 children 为单元素时末尾手动节点不进 diff）；挂 wrapper 兄弟节点不触发 hover-card。React 提交可能挤位，每次对账 `if (el !== parent.lastChild) parent.appendChild(el)` 挪回。
- 原生上下文按钮增强（`data-testid="chat-context-usage-trigger"`）：环填充 + 四档色 `data-zusage-band` + 按钮内百分比。显示层**优先镜像原生 aria-label 已用/总量**（`parseNativeCtxLabel`，宿主 taskUsage store、与悬停面板同源，压缩后立即刷新——issue #172；数字是普通千分位格式，面板摘要才是 compact 万/K，正则只认前者）；解析不出（无数据回退标签）才回退 `ctxBandOf` 的 DB 口径，ctxOv/nativeCtxVal 窗口优先级只作用该兜底路径与 acWarningText；原生 label 可解析时 DB 缺 context_window 也增强，两源全缺才 `restoreCtxButton` 还原（还原共用同一解析器推回 dashoffset，英文 UI 同样正确）。档位 exc 过程态在镜像下仍优先；`lastBand` 本体不改写（DB 口径继续供 acWarningText）。额度 chip 挂同一按钮左侧，沿用同一双 reapply/还原契约。**增强开关（v156，issue #141）**：`localStorage zusage3.ctxEnh` 缺省开、仅显式 `"0"` 关（⚙ → 通用「上下文按钮增强」，纯渲染端偏好，不进 config.json）；关闭分支在 `enhanceCtxButton` 早退前还原已增强按钮并**重跑 `syncResetBadge`**——`restoreCtxButton` 会顺带清理 `.zu-ctxrst` 徽标（两者都借按钮定位），开关只隔离增强不隔离徽标，别把「徽标与增强独立」理解成 restore 不动徽标。
- 设置页是同窗口覆盖层：冒条排除标记必须用三层并集 `[data-testid="settings-page"], [data-settings-content-frame], [data-settings-panel-frame]`；权限面板不是 Radix dialog、渲染在 SessionPane 子树内，拦截点在 `inSettingsView` 派发处与 `track` 显隐处。新增排除调用点时注意 `tests/overlay-port-patches.test.cjs` 对源码切片的计数断言。
- 浮层打开外链走 preload 桥 `window.zcode.openExternal(url)`（系统默认浏览器），`window.open` 会被客户端内置浏览器接管，只作兜底。
- Radix hover-card / AlertDialog 无 forceMount、关即卸载：注入其中的 UI 必须 body `MutationObserver`（rAF 去抖）+ heavy（600ms）双触发重注入、DOM 存在性幂等（多实例安全）；插入锚用双类名指纹（如 `border-t` + `pt-2`），单类名会插错段；缺锚则容器尾 + 位置兜回。
- 「上下文容量」弹层内的压缩上下文按钮（用户拍板的最终形态）：主通道=沿触发元素 `__reactFiber$` 上行取宿主 `onSendCompressionCommand("/compact")` 直接调（不碰输入框草稿与发送键，流式中交引擎排队）；字面 `/compact` 经官方 E2E 输入桥 `__zcodeLexicalInputE2E` 仅作兜底，且流式中/草稿非空/发送键 disabled 三重门控全部前置到 setText 之前（拒绝不残留草稿；Lexical contenteditable 直写 DOM 不进 EditorState，该路径禁用）。提交函数必须在**弹框打开瞬间**解析并缓存目标会话与锚点几何——确认时弹层已被 Radix 卸载，重解析会退化为"离视口左上角最近"而把命令发进错误分栏。确认框 hint 必须保留：压缩摘要是非流式请求、通常 2–4 分钟无进度反馈，生成中发新消息会打断压缩（TURN_CANCELLED）；Enter 确认限定焦点在弹框内。

## 4. tooltip 与监听预算

- Chrome 在悬停链重算时会向 `documentElement` 补发**伪 mouseleave**（格内 flex 空隙、tooltip 子元素间必发）。边界判定用 `document.querySelectorAll(":hover")` 的最深元素甄别：最深为 null/body/documentElement/IFRAME/WEBVIEW 才真离开，否则忽略交回 mousemove 流。`relatedTarget` 与坐标 `elementFromPoint` 方案已实测否决。伪事件只在真浏览器出现，VM/stub 测不出，改悬停边界必须 Playwright 实测（见 [tests.md](tests.md)）。
- 滚动收起分层：`hideTipsOnScroll` 只收消息流内随滚动移位的 rateTip；quotaTip/gitTip 挂在固定的 composer 工具行，滚动豁免；chip 随宿主 React 重建而 detach（无 mouseleave）时由扫描 tick 的 `isConnected` 健康检查兜底收起。
- 监听预算：浮层 tooltip 共用**单个** scroll 监听，新增浮层不得再加 scroll/resize 监听；每个 tooltip 有解绑路径。
- 凡「周期对账 + innerHTML 重写」的浮层（gitTip/quotaTip/chip）必须走内容签名幂等（`__zuTipSig`/`__zuSig`，签名不变跳过重建），否则滚动拖拽被打断；数据真变时保留 scrollTop 后一次性重建。
- 自绘 tooltip 走 rateTip 同款独立浮层模式；标题与 ⚙ 面板开关标签是两套措辞，文档按两套区分。
- **激活方式（v249；v247 的 1000ms 停留定时器链已按用户裁定整体移除）**：`zusage3.tipClick` 缺省关=**即时悬停原语义**（mousemove 命中判定与 v246 逐行为一致，含 .zu-sub 即时 preview），仅显式 `"1"` 开=点击激活：mousemove 在保活/收起分支之后单行早退（点开的 tooltip 仍靠上方分支保持/收起），打开一律走 `bar.click` 的 `.it` 分支（再点同格 `re-click` 收起、`focusTipAt` 记录 focusin 时刻防「focusin 先打开、click 紧接着按再点关闭」的首击抵消；.zu-sub 的 click→pinned 打开是 v246 既有契约不受开关影响），子代理 hover preview 在点击模式下关闭。⚙ 通用分区「点击激活悬浮窗口」，两处回填（buildPanel 尾部 + syncPanel）必须齐。键盘 focusin 两模式都即时打开。fxTip、速度柱状图信息卡、6 个工具栏 chip 与宿主原生 hover-card 不在此链内，别误接；勿把 v247 的 hoverSchedule/hoverCheck/hoverCancel 定时器链接回来。

## 5. 展示口径（写文档、解释浮层的唯一依据）

- 格顺序（v213 用户规格 2026-11-02 调整）：生成速度 → 本轮 → 会话累计 → **今日合计** → 项目累计 → 工具调用 → 子智能体 → ⚙（速率 tooltip「状态条摘要」行序随同）。状态条**没有**「上下文容量」格，该口径唯一承载处是原生上下文按钮增强；子智能体格始终展示（零值显 0，运行指示按 30 秒内有子代理请求点亮）。
- 本轮格的 requests 是模型请求「次」不是轮数；格面只显 token/命中率/次数——**时长与首字段已移除（v211 用户规格）**，耗时只在 tooltip。tooltip 三行口径（v211 起）：「平均耗时/平均延迟」=快照 `avg_duration_ms`/`avg_ttft_ms`（Python 侧对 model_usage 该轮已完成 main_turn 行 **>0 样本**求均值；turn_usage 的 `ttft_ms` 聚合列实测既非 Σ 也非 μ、不可依赖；旧快照/远端旧版缺字段整行不渲染），加「本轮总耗时」`lt.duration_ms`（Σ 各请求）。v211 前「单次耗时/首字延迟」是最近一次请求值（`last.duration_ms`/`ttft_ms`），快照 `last` 结构仍保留供速率/门控消费。本轮与「最近一段」是轮级与段级两个口径。
