# ZCode 3.19.1 自动压缩引擎兼容

## 范围与规则

- `engine-patch.cjs` 的 `ENGINE_TARGETS` 登记 Windows ZCode 3.19.1.10833 样本引擎。由引擎补丁器负责识别、应用和还原；原版 `zcode.cjs` 以 SHA-256 优先识别，`getAutoCompactThreshold` 的判定表达式使用 `Uue(e.bufferTokens)` 和 `KKo`，全文件必须唯一命中。
- 沿用同版本漂移规则：指纹不匹配时，只有桌面 build 匹配登记版本且该版本锚点唯一才应用；锚点缺失或重复则拒绝写入。3.19.0 保留原指纹与 `Hue` / `xZo` 锚点。配置键、阈值计算、未配置时的宿主默认行为均不变。
- 共享模块同步到插件副本。客户端引擎已有同款补丁时重新识别，不重复写入；首次应用后由下次启动的 agent 加载。桌面渲染桥继续由安装链自动推导，不新增 3.19.1 渲染桥登记，不改变离线 CLI 的版本限制。

## 验收

| 场景 | 预期 | 验证 |
| --- | --- | --- |
| 校验过指纹的 3.19.1 原版引擎 | 在临时副本应用成功；第二次不改字节；产物语法有效；还原后与原版逐字节相同 | 真实引擎副本往返，`node --check` |
| 3.19.1 已有同款补丁 | 识别为 `applied`，不改写原文件 | 真实的已补丁引擎副本 |
| 同版本漂移、不同版本或锚点不唯一 | 仅匹配 3.19.1 build 且新锚点唯一时允许漂移兜底；未知 build 或旧锚点仍拒绝；3.19.0 保持自身锚点 | `tests/engine-patch.test.cjs` 的登记表与隔离行为回归 |
