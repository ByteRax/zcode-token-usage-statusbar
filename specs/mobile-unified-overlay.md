# 远控统一桌面状态条

## 产品规则

- 远控页面只使用桌面 `overlay.js` 的状态条、图标、样式、tooltip、设置和挂载逻辑；删除手机独立 chips 条及其设置面板。构建时将当前桌面分片生成的同一份代码嵌入正式/调试脚本，禁止依赖 CDN main 取得另一代 UI。
- 手机接收端只负责官方中继旁听、重组、校验、显示偏好握手和受限快照适配。旧宿主只发送 chips 时显示“请更新桌面插件”，不渲染另一种状态栏。
- 本地与 WSL/SSH 均下发目标专属数值投影快照。真实工作区身份和路径仅留在主进程查询/验证，不能进入 wire；模型、工具与子代理名称沿用现有匿名化规则。保留已有目标 taskId 绑定，新增随机 `binding` 区分同 SID 不同身份及连接代次。
- wire 数据形态为 `{zm:1,target:{taskId},mine,scopeKind,binding,snap,ts}`；不可用帧携带相同目标绑定及 `state:"unavailable"`，无 snap/chips。`binding` 只在当前目标/桥有效，目标或身份改变时重新生成；不能用路径哈希作为标识。
- 桌面 overlay 新增受限的移动快照上下文 `mobile:{taskId,binding,scopeKind,state}`。该模式仅在远控接收端显式启用时消费，使用快照中唯一匹配行；页面当前 SID 与目标不同则同一桌面条显示等待数据，不能使用旧 today 或其它会话。普通桌面 scope/sessionFor 语义保持。
- 移动上下文中缺失的统计不可伪造 0；指标确有数值 0 时才可展示 0。查询失败、旧帧、缺身份与目标变化均不能展示本地或其它目标替身。速度历史及远端 today 缓存不能跨 binding 继承。
- 超限时先裁剪投影内的可选明细，仍超限发送目标不可用状态；禁止把本地帧改成 remote 或回退 chips 条。
- 数据收到后超过 30 秒没有新统计，或载荷时间戳已超过 30 秒，通过同一桌面条进入不可用空态；能力公告不续期，新鲜的同 binding 快照可恢复。桥和来源接管时清残片并拒绝退役来源，禁止迟到旧片恢复上一目标。
- 调试面板只保留路径级连接 URL，移除 userinfo、query、fragment；正式版不创建调试面板。脚本注入、导航和热替换不得重复注册消费者。

## 状态所有者

- 宿主 `mobileTaskView` 与唯一 live stash bridge：当前可见目标及桥代际的可信来源。
- `inject-main.cjs`：桌面窗口、工作区及任务证据校验和实时目标复验；不得通过删除信任门绕过真实故障。
- `mobile-relay.cjs`：真实 SID+identity 查询、数值投影、匿名 binding、目标专属下行；目标撤销保留宿主原有零查询规则。
- `src/mobile/`：连接级配置/顺序/分片状态及帧校验；只调用桌面渲染接口。
- `src/overlay/`：唯一的状态条/UI 与移动上下文空态；手机不复制渲染代码。
- `scripts/build_mobile_userscript.py`：嵌入与桌面构建逐字节相同的 overlay，产出两变体。

## 验收

1. Chrome 真实远控页本地→WSL→本地切换均只出现 `.zusage-root`，不存在 `.zm-root`；设置/tooltip 由同一桌面代码创建。
2. 切换期间或查询失败显示同一 UI 的等待/不可用状态；没有上一目标 today、速度或其它会话数据。
3. 远端帧的 snap 只包含目标统计与对应远端 today，真实编码帧无工作区路径、身份、标题、正文或凭据；同 SID 不同身份使用不同 binding。
4. 旧帧/迟到分片、能力公告、重连、disable 与多桥歧义均不能恢复旧目标数据；配置上行仍必须获得同 socket 的能力确认。
5. 自动化覆盖生产者投影、接收端验证、桌面移动上下文与构建一致性。真实 Chrome 记录帧摘要、DOM 数量、可见值与控制台；冷文件只安全部署并报告待重启，不自行重启客户端。

## 已有实机证据

Chrome 已直接注入并收到本地 `scopeKind:local` + snap，桌面 overlay 正常；切入在线 WSL 后只收到能力公告，稳定运行中继诊断 `target:false`，切回本地立即恢复。远端故障发生于主进程目标信任门之前，尚不能归因于远端查询失败。修复条件必须以进一步宿主/运行时证据为准。
