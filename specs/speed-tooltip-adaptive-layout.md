# 速度 Tooltip 自适应布局

## 问题与范围

速度 V2 卡默认 760×300 CSS 像素；宿主字号增大或可用视口变窄时，标题、筛选栏和左侧统计内容可能超出固定高度，导致彼此重叠。物理屏幕分辨率不能直接决定 CSS 布局。本规格只覆盖 V2 速度卡，不调整统计数据、旧版卡、今日卡或用户字号设置。

## 行为

- 卡片以默认字号的 760×300 构图为基准，字号异常增大时优先以有下限的局部比例缩放协调文字、间距和图表；不修改宿主全局字体或其他卡片。空间仍不足时再按内容扩展并允许滚动。
- 宽度需求不包含图表横向滚动内容；长模型名允许省略，保留既有完整名称提示。少量柱靠左，多柱有余量时适度均匀铺满，柱宽不拉粗；超过容量仍可横滚。
- 宽高受当前视口和边距约束；放不下时内容保持自然尺寸并可纵向滚动，图表保留自身横向滚动。左侧各行不得重叠。
- 普通状态条与精简模式均适配。保持交互、焦点、筛选、滚动记忆、图表 Portal 及月历尺寸语义；关闭后重开重新计算，打开期间避免不必要的尺寸抖动。
- 不增加每帧测量或全局滚动／缩放监听；实际显示及内容重建时同步测量，视口变化复用现有定位周期处理。

## 验收

自动化覆盖分三层：VM 行为断言锁定缩放下限、左卡 320px 钳制、模型名缩字（1px 容差与 10px 下限）、柱组 n≥10 铺满阈值与 drawTip/showTpsTip 生产接线；Electron QA 几何断言（tests/speed-tooltip-host 的 ZU_GEOMETRY_ONLY 门）覆盖 14、17、20px 宿主字号与精简容器下标题、数字、模型、统计区互不相交及月历重建。窄窗与受限高度、普通容器及键盘可达性由 QA 截图演示流与 Windows 真机目测覆盖。模拟环境不能代替 Windows 真机验收。
