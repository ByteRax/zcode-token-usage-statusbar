# 统计卡大字号布局

本轮、会话与今日统计卡在宿主字号增大或窗口变窄时，输入标题与缓存命中率不得重叠或逐字折行；空间不足时允许徽标自然换行。卡片标题行（「会话累计」等大字标题与拼接的名称）恒单行：标题文字不得折行或压缩；会话名超长时在标题行剩余宽度内省略号截断（上限 360px），不得把标题大字挤成逐字竖排、不得溢出或撑破卡片；右侧范围胶囊保持完整不换行不压缩。标题行三项（大字标题、名称、范围胶囊/Tab）垂直居中对齐（align-items:center，不用 baseline——后者把胶囊中心拖低）；项目卡紧凑样式中标题容器内部 `.zu-pj-title` 同样用 center，项目名与大字标题垂直居中。正常长度名称的排版不变。

其它浮层的长动态文本（用户/数据可控的名称、URL、错误原文）遵循同一原则：flex 行内的名称项必须可收缩（min-width:0）并省略号截断或以 anywhere 断行，不得挤压兄弟项或撑破容器；不可收缩的 nowrap 项只允许静态短文案。具体契约：增强历史小浮层相位文案（可含上游错误原文）单行省略；精简摘要 rt-models 模型名键列带宽度帽（table-cell 的 ellipsis 须有 max-width 才成立）；子代理任务页 agent 名副标题可收缩省略并 title 全名；额度浮层标题（套餐/供应商名）anywhere 断行；data-tip 伪元素气泡（探测状态/模型胶囊/轮播）anywhere 断行；词包弹窗标题 packId 回退省略；速度 V1 回退卡估宽分级（fit2/fit3）同时覆盖左卡与 legacy hero 双作用域；工作流 run chip tooltip 作用域样式必须命中浮层宿主真实类名（zusage-subrate-tip）。模型明细的费用及其他数值必须可完整查看：模型名放不下时优先在可读下限内缩小字号，仍放不下才省略并保留完整名称提示；极窄窗口允许可见的横向滚动。其他 Tooltip 中被裁切的模型名遵循相同原则，不改变模型标识。默认字号下保留现有排版，不更改用户全局字号、费用开关或统计口径。

验收覆盖中文／英文、14／17／20px 字号、长模型名、超长会话标题（含无空格长 URL 形态）、100% 缓存命中率、费用开启／关闭及窄视口；检查同样使用紧凑样式的项目和工具卡无回归。浏览器模拟不代替 Windows 实机。
