# 统计卡大字号布局

本轮、会话与今日统计卡在宿主字号增大或窗口变窄时，输入标题与缓存命中率不得重叠或逐字折行；空间不足时允许徽标自然换行。模型明细的费用及其他数值必须可完整查看：模型名放不下时优先在可读下限内缩小字号，仍放不下才省略并保留完整名称提示；极窄窗口允许可见的横向滚动。其他 Tooltip 中被裁切的模型名遵循相同原则，不改变模型标识。默认字号下保留现有排版，不更改用户全局字号、费用开关或统计口径。

验收覆盖中文／英文、14／17／20px 字号、长模型名、100% 缓存命中率、费用开启／关闭及窄视口；检查同样使用紧凑样式的项目和工具卡无回归。浏览器模拟不代替 Windows 实机。
