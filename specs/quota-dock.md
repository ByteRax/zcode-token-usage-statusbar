# 侧栏额度环

- 齿轮所在且通过侧栏结构校验的 footer 承载一个 dock，dock 为首个元素。一个 pane 持有它的数据、刷新事件和位置观察器。持有者退出或失去可显示的额度后，下一个符合条件的 pane 可接手。
- React 摘除 dock 或替换 footer 后，观察器把原节点放回有效 footer。位置已正确时不写 DOM。无锚点时按现有对账隐藏，禁用或销毁时断开观察并释放事件。
- 每个有效窗口显示剩余量，最多五列。有限的已用百分比钳至 0–100 计算剩余量，档位按已用量判定。橙色从 70% 开始，满档保留红粉呼吸。显示 0% 时隐藏弧线，显示 100% 时画整环。单窗口且有有效时间时显示重置或到期。
- 重建签名包含实际弧长、档位和可见时间。重建失败时保留上次成功的内容和读数，下次对账重试。余额、Key 额度和提示沿用文字形态。
